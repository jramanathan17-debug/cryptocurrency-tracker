# Cryptocurrency Price Tracker

A Python-based mini project that automatically collects cryptocurrency market information using Selenium and stores the collected data in a CSV file.

## 📌 Project Overview

The Cryptocurrency Price Tracker collects:

- Coin Name
- Price
- 24h Change
- Market Cap
- Timestamp

The collected data is stored in `crypto_prices.csv`.

## ✨ Features

- Automated cryptocurrency data collection
- Selenium web scraping
- Top 10 cryptocurrency data collection
- Data cleaning
- CSV storage using Pandas
- 24h Change filtering
- Price filtering
- Headless Chrome execution

## 🛠️ Technologies Used

- Python 3.14.5
- Selenium
- Pandas
- WebDriver Manager
- Google Chrome
- CoinMarketCap
- CSV
- Visual Studio Code
